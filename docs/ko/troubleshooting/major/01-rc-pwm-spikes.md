# RC PWM 신호 튐과 의도하지 않은 바퀴 움직임

[English](../../../troubleshooting/major/01-rc-pwm-spikes.md) | [트러블슈팅 목차](../../troubleshooting.md)

**분류:** 중요 이슈 · 기존 문서와 코드에서 재구성한 기록

## 1. 문제정의

실물 로봇 시험 중 조작 의도와 다르게 바퀴가 순간적으로 움직였고, FrSky X8R PWM 값을 시리얼로 확인했을 때 신호 튐이 관찰됐다. 제어 게인을 변경하기 전에 입력 신호 문제와 모터 구동 문제를 분리할 필요가 있었다.

## 2. 해결방법 안들 설정

검토할 해결안은 ① 금속 구조물 주변 수신기·안테나 배치 변경, ② PWM 배선과 접속 상태 개선, ③ 입력 필터·중립 데드밴드·활성화 지속성 검사였다. 수신기 단독 시험으로 원신호를 먼저 관찰하고 하드웨어 조건과 소프트웨어 처리를 구분한다. 이 목록은 기존 기록에서 재구성한 검토안이며, 실제 실험의 정확한 시간순서를 뜻하지 않는다.

## 3. 해결방법 실행

기존 기록에는 수신기 PWM 단독 확인, 여러 차례 접속 수정, 금속 근접에 따른 증상 변화, 알루미늄 포일 적용 후 악화가 남아 있다. 최종 코드는 throttle·steering 필터 alpha 0.4, engage alpha 0.02, 중립 오프셋, 50 us 데드밴드, 활성화 지속성 검사를 구현한다. throttle 데드밴드 기준은 1488 us지만 정규화 기준은 1491 us이고 steering 기준은 1492 us이다. 이를 완전히 통일된 보정값으로 설명하면 안 된다. 배치 변경과 신호–GND 근접 배선은 대응 방안이며 통제된 실험의 전후 노이즈 감소율은 없다.

## 4. 경험의 재해석

수신기 배치와 배선 품질도 제어계 설계에 포함해야 한다. 필터로 입력 노이즈의 영향을 줄여도 개별 스파이크의 원인이 RF 환경, 유도 노이즈, GND 기준 변동 중 무엇인지는 증명되지 않는다. 금속·포일 관찰은 배치 영향이라는 가설을 뒷받침하지만 EMI 원인을 측정해 확정한 것은 아니다.

## 5. 정리

결과：PWM 필터·데드밴드·오프셋·활성화 지속성 검사가 구현되어 있다. 스파이크 감소율의 정량 데이터는 공개되어 있지 않다. `PrintRcSignals()`, 필터 상수, `EngageMotors()`와 수신기 테스터를 확인한다. 후속 비교에는 원시·처리 후 PWM, 수신기 위치, 배선 조건, 의도하지 않은 명령 횟수를 기록한다.
